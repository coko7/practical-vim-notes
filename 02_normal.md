# Chapter 2: Normal Mode

- `u` undo reverts last change -> chunk your undos!
- [VimGolf](https://www.vimgolf.com/)
- `<C-a>` increment number (current pos or line-look ahead) (works with count)
- `<C-x>` decrement number (current pos or line-look ahead) (works with count)
- `!` Filter `{motion}` lines through external program
- `gU`/`gu` convert to UPPERCASE / lowercase 
- When an Operator command is invoked in duplicate, it acts upon the current line
- Operator-Pending Mode: state between operator and motion
