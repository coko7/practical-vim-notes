# Chapter 4 Visual Mode

Visual mode commands:
- `<C-g>` switch to Select mode
- `gv` reselect last visual selection
- `v` / `V` / `<C-v>` switch between visual modes easily
- `o` go to other of highlighted text
- [Vimcasts](http://vimcasts.org/e/2)
- `r` will replace entire selection with character (Visual, V-Line and V-Block)
